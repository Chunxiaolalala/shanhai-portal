# _inspiration/ — 外部灵感图暂存区

> **这个目录不参与工程。** 不写进 `reference-mapping.json`，不被任何组件消费，不打包上线。
> 放着只是为了让「借来的审美」和「自己的资产」物理隔开。

## 放什么

从花瓣 / Pinterest / 站酷 / 故宫名画记 / 中华珍宝馆 / 书格 / Unsplash 等站截来的参考图、色卡截图、局部裁切。

## 不放什么

- H3-Image 的出图（那些进对应的 `Vxx_` 目录）
- 你自己拍的、或明确公版可直接用的最终资产（进 `Vxx_`，并在 MAPPING 里记来源）
- 任何最终会上线到主页的图

## 为什么隔开

1. **版权**：你已确认主页不商用（C06），参考图只作模型输入；但花瓣 / 站酷 UGC 版权来源不清，混进正式资产目录以后说不清。
2. **调性**：V01 是后面 9 张唯一的色板来源。外部成品图一旦和母版混放，很容易顺手垫进去，把别人的构图带进整套视觉。
3. **工程**：`Vxx_` 目录的 `status` 改成 `ready` 就意味着开发侧会去标定参数，这个语义不能被灵感图污染。

## 命名建议（随意，不强制）

```
insp-mood-01.jpg        调性 / 色板
insp-fog-01.png         雾感局部裁切
insp-guhua-01.jpg       古画远山或留白局部
insp-palette.txt        抄下来的 HEX 色值
```

## 使用规则

- **主要用途：垫给你自己** —— 校准审美、提炼提示词形容词、挑 H3 出图时有个标准。
- 若要垫给 H3 当执行参考，见 `生成提示词_MiniMax_H3.md` 第 0A 节：最多 2 张、分工明确、无主体无文字、并追加护栏句。
- **V01 母版建议纯文生图，零外部参考图。**
